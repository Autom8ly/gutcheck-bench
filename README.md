# gutcheck-bench

**Run open System 1 decision models on your own 8 GB GPU.** Benchmarks, quantization patches and adapters for teams that need Jev-style typed decisions but can't send data to an external API.

> **Mostly AI-generated.** This repository and the accompanying article were largely generated by an AI assistant (Claude, by Anthropic), directed by Mark Vange in response to specific use cases in high-compliance environments. All measurements were taken on real hardware (below), and everything needed to reproduce them is here.

📄 **Article:** [Jev is the best decision model. Here's what to run when you can't use it.](https://claude.ai/artifact/HexfBMYDSXGvKnnQw9qj5s)

## What this is

[Jev](https://typesafe.ai) (TypeSafe) answers typed questions (pick one, yes/no, score) with probabilities instead of generated text. Within a week of its release, seven open-source look-alikes appeared. We ran 14 configurations of them, one at a time, on a single **RTX 4060 (8,188 MiB)**, and scored every one on the same 764 out-of-domain decisions from Kev's public `transfer-v4` suite, alongside Jev itself through TypeSafe's API.

## Reproduce

1. Clone [Kev](https://github.com/jaredpalmer/kev) (commit `105c76958d4c`), `uv sync --extra serve`, and apply `patches/kev-quant.patch` if you want the quantized models. Kev's benchmark tool and `transfer-v4` suite are the common yardstick.
2. Start any `/v1/systemone` server (a tool's own, or one of the adapters here), then score it:

   ```bash
   uv run python -m kev.benchmark --remote http://127.0.0.1:8008 \
       --remote-model kev-latest --suite evals/v4/transfer-v4 --out runs/my-tool
   ```

3. Or let the harness do the start, measure and stop for you (it expects the tool checkouts under `~/jev-eval/`, as in our runs):

   ```bash
   ./harness/bench_remote.sh kev-4b-4bit 8202 ~/jev-eval/kev kev-latest evals/v4/transfer-v4 -- \
       env KEV_FUSED=0 KEV_CUDA_GRAPHS=0 KEV_QUANT=4bit uv run --no-sync python -m kev.serve --run jaredpalmer/kev-4b --port 8202
   ```

Kev-9B also needs `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`. For Jev, point `--remote` at `https://api.typesafe.ai` and set `KEV_REMOTE_API_KEY`.

## The humanness experiment

Ten models (Opus 5.5, Sonnet 5, Haiku 4.5, Fable 5.1, Opus 4.6, OpenAI Codex, OpenCode big-pickle, qwen3:8b, hermes3:8b, gemma4:e2b) each rewrote the article's opening paragraph to sound human while keeping every fact ([`brief.txt`](humanness/brief.txt), [`versions.json`](humanness/versions.json)). We added two deliberately extreme controls ([`controls.json`](humanness/controls.json)) and asked Kev-4B and Jev three questions about each: was it written by a human, how natural does it sound, and which of the ten sounds most human (averaged over ten rotations of the option order).

**Kev could not tell:** it scored the stiff and casual controls within 0.014 of each other. **Jev could:** 0.25 against 0.59 on the human question, and 0.14 against 0.85 on naturalness. See [`kev_humanness.json`](humanness/kev_humanness.json) and [`jev_humanness.json`](humanness/jev_humanness.json). This is one small experiment, not a benchmark.

## Related work

Independent benchmarks of the same category, which agree with ours on the main points (Jev leads; Von is the strongest small local model):

- [jabr/classifier-benchmark](https://github.com/jabr/classifier-benchmark): 866 synthetic cases across 49 tasks.
- [umstek/zero-shot-ie-bench](https://github.com/umstek/zero-shot-ie-bench): 38 zero-shot extraction, classification and typed-decision systems, local and hosted, in nine languages.
- [scienthoon/jev-ood-calibration](https://github.com/scienthoon/jev-ood-calibration): whether Jev's probabilities stay honest on a task it can't have seen.
- [cacan/system1-bench](https://github.com/cacan/system1-bench): Laya and general LLMs against Jev on support-triage cases; some answer keys were aligned with Jev's own answers.
- [jaredpalmer/kev](https://github.com/jaredpalmer/kev): Kev's own frozen suites and benchmark tool, used to score everything here.

## Caveats

One public suite, one GPU, one machine. Your own decisions may rank these tools differently, so test on a labelled set from your domain before choosing. Latency is one request at a time and includes a local HTTP round trip; Jev's includes the internet round trip from our test machine. All seven projects were days old when tested and are changing quickly.

We are not affiliated with TypeSafe or with any of the projects tested. Jev and TypeSafe are TypeSafe's names; "System 1" refers to the general idea of fast, intuitive decisions.
